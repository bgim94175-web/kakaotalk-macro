# UI 개편 v3 — 설계 명세

> **문구는 `docs/TONE.md` 를 따른다.** 이 문서의 예시 문구는 구조 설명용이며,
> 실제 구현 시 반말체는 전부 비즈니스 문어체로 작성한다.

사용자 피드백 그대로: **"카테고리가 너무 복잡하고, UI마다 구분이 안 돼서 뭘 어떻게 설정해야 할지 모르겠다."**

원인은 명확하다. 매크로 화면 한 장에 **설정 행 25개 + 아코디언 7개**가 쌓여 있다.
아코디언은 접혀 있으면 안에 뭐가 있는지 모르고, 펼치면 다른 것과 섞여서 경계가 사라진다.

주력 기능은 **자동발송 매크로**다. 봇 두 개는 부가 기능으로 둔다.

---

## 1. 핵심 원칙

1. **한 화면에는 한 가지 일만.** 설정 상세는 아코디언이 아니라 **전용 서브화면**으로 연다.
   (안드로이드 설정앱과 같은 패턴 — 사용자가 이미 아는 구조라 설명이 필요 없다)
2. **목록 화면은 "현재 값"을 보여준다.** 제목만 있는 행은 금지. 항상 `제목 + 지금 값 요약 + ›`.
   값을 보면 설정할 필요가 있는지 없는지가 바로 판단된다.
3. **한 화면에 보이는 항목은 최대 7개.** 넘으면 구분선으로 묶고, 그래도 넘으면 화면을 나눈다.
4. **섹션은 3개 이하.** 각 섹션에 짧은 제목을 달아 경계를 만든다.
5. **설정이 안 끝났으면 그걸 먼저 말한다.** 뭘 해야 하는지 모르는 상태를 만들지 않는다.

## 2. 화면 구조

```
홈           매크로          봇            내정보
 │            │              │              │
 │            ├─ 메시지       ├─ 방 관리봇    ├─ 라이선스
 │            ├─ 대상 방 ──┐  └─ 미니게임봇   ├─ 카톡 계정
 │            ├─ 발송 주기 │                 ├─ 권한
 │            ├─ 사진 첨부 │                 ├─ 로그 · 진단
 │            ├─ 메시지 추적│                 └─ 서버 설정
 │            ├─ 자동응답   │
 │            └─ 발송 제한  │
 │                         │
 └─────────────────────────┴─ 방 관리 화면 (계정별 · 다중선택 · 삭제)
```

서브화면은 **풀스크린 푸시**다 (`Nav.push(View, "제목")` / `Nav.pop()`).
상단에 `‹ 뒤로  제목` 바가 고정으로 붙는다. 하단 탭바는 서브화면에서 숨긴다.
안드로이드 뒤로가기 키가 `Nav.pop()` 과 연결돼야 한다 (`MainActivity.onBackPressed`).

## 3. 홈 — 상태와 "다음 할 일"만

카드 3~4개. 설정은 여기서 하지 않는다.

1. **상태 카드 (크게)**
   - 매크로 켜짐/꺼짐 토글 (홈에서 바로 끄고 켤 수 있어야 한다 — 제일 자주 하는 동작)
   - 켜짐이면: `다음 발송 21:34 (12분 후)` · `금일 8회 발송`
   - 꺼짐이면: `미사용` 만
2. **준비 체크리스트** — **미완료 항목이 있을 때만** 보인다. 다 되면 카드째 사라진다.
   각 줄: `항목명 + [설정]` 버튼. 순서대로:
   - 카톡 알림 접근 권한
   - 배터리 최적화 제외
   - 발송 메시지 (비어 있으면)
   - 대상 방 (0개면)
   - (사진 쓸 때만) 접근성 · 다른 앱 위에 표시
3. **기능 카드 3개** — 매크로를 맨 위에 크게, 봇 둘은 한 줄씩 작게.
   꺼진 기능은 `[구매하기]`.
4. **최근 활동** 4줄 + `전체 로그 ›`

실패 경고(사진 전송 실패 등)는 1번 카드 **바로 아래**에 한 번만 띄운다.

## 4. 매크로 탭 — 목록만

아코디언 전부 제거. 행을 탭하면 서브화면으로 간다.

```
┌─────────────────────────────────────┐
│  자동발송                    ●━━     │   ← 토글. 아래에 "다음 21:34 · 오늘 8번"
└─────────────────────────────────────┘

  보내는 내용
┌─────────────────────────────────────┐
│  메시지        안녕하세요 오늘도…   › │
│  대상 방       3개 · 부계정 1개 포함 › │
│  발송 주기     20~40분마다          › │
└─────────────────────────────────────┘

  추가 기능
┌─────────────────────────────────────┐
│  사진 첨부     3장 · 매번           › │
│  메시지 추적   2개 켜짐             › │
│  개인톡 자동응답  꺼짐              › │
└─────────────────────────────────────┘

  안전장치
┌─────────────────────────────────────┐
│  발송 제한     23~08시 쉼 · 하루 200 › │
└─────────────────────────────────────┘

        [ 즉시 발송 ]
```

값 요약 규칙:
- 메시지: 첫 줄 20자 + `…`. 비어 있으면 **AMBER** 로 `설정 필요`
- 대상 방: `N개`. 0개면 **AMBER** 로 `설정 필요`. 계정이 2개 이상이면 `· 부계정 N개 포함`
- 사진 첨부: `안 보냄` / `N장 · 매번` / `N장 · 3번째마다` / `N장 · 수동만`
- 메시지 추적: `꺼짐` / `N개 켜짐`
- 자동응답: `꺼짐` / `켜짐 · 모든 1:1`
- 꺼진 기능은 값 글자를 **DIM** 으로, 켜진 건 **TEXT** 로 — 색만 봐도 on/off 가 구분된다

## 5. 방 관리 화면 (핵심 개편)

`대상 방 ›` 에서 열린다. 여기서 **선택 · 삭제 · 추가**를 다 한다.

```
‹ 뒤로   대상 방

  카카오톡 계정 2개 감지됨          [계정 설정 ›]

  ▸ 본계정 (김부성)
  ☑ 가족방              단체 · 3분 전
  ☑ 회사 공지방          단체 · 1시간 전
  ☐ 홍길동              1:1 · 2일 전        ✕

  ▸ 부계정 (부캐)
  ☑ 오픈채팅 A          단체 · 10분 전
  ☐ 김철수              1:1 · 5일 전        ✕

        [ 직접 입력 추가 ]
        [ 감지 목록 초기화 ]
```

규칙:
- **체크박스 다중 선택.** 체크하면 즉시 저장(확인 버튼 없음).
- 각 방에 **배지**: `단체` / `1:1`, 그리고 `마지막 감지 시각`(3분 전 / 어제 21:30).
- **✕ 버튼으로 개별 삭제** — 멤버 이름이 방으로 잘못 들어간 항목을 여기서 지운다.
  선택된 방을 지우면 선택도 같이 풀린다. 삭제는 확인창 없이 바로 하고 **[되돌리기]** 스낵바를 5초간 띄운다.
- **[감지 목록 전체 지우기]** — 확인창 필요. 선택된 방은 유지하고 감지 캐시만 비운다.
  (옛 버전에서 멤버 이름이 잔뜩 쌓인 사용자를 위한 청소 버튼)
- **직접 입력 추가** — 감지 안 된 방을 손으로 넣는다. 계정도 같이 고른다.
- 계정이 1개면 `▸ 본계정` 머리글과 계정 안내 줄을 **숨긴다** (불필요한 복잡도 제거).
- 감지된 방이 0개면: `감지된 대화방이 없습니다. 카카오톡 메시지를 1회 수신하면 자동으로 등록되며, 직접 입력하여 추가할 수도 있습니다.`

## 6. 카톡 계정 (듀얼 메신저) — 신규

한 폰에 카톡을 여러 개 깔아 쓰는 경우(삼성 듀얼 메신저, 사직 업무 공간)를 지원한다.
v1.8 에 있던 기능인데 재작성하면서 빠졌다.

### 감지
- 알림마다 `StatusBarNotification.getUser()` (UserHandle) 로 계정을 구분한다.
  같은 패키지라도 프로필이 다르면 UserHandle 이 다르다.
- 계정 표시 이름은 `Notification.EXTRA_SELF_DISPLAY_NAME`(내 카톡 프로필 이름)을 쓰고,
  없으면 `본계정` / `부계정 2` 처럼 순번으로 붙인다. 사용자가 **이름을 바꿀 수 있어야 한다.**
- 계정 키는 `UserHandle.hashCode()` 를 문자열로 (직렬화 가능해야 한다).
  `getUser()` 를 못 읽는 기기는 단일 계정(`"0"`)으로 취급한다.

### 데이터 모델
- 방 식별자를 `계정키 + "\u0001" + 방이름` 으로 한다 (같은 이름 방이 두 계정에 있을 수 있다).
  `RoomRef { String acc; String name; }` + `key()` / `parse()` 를 두고 전부 이걸 쓴다.
- **하위호환**: 기존 저장값은 계정 구분자가 없는 방 이름이다. 읽을 때 계정키를 `"0"`(기본 계정)으로 채워라.

### 설정
- `Settings.accounts` : 대상 계정 키 목록. **비어 있으면 모든 계정** (기존 사용자 = 자동으로 전부).
- 내정보 탭에 **카톡 계정** 화면: 감지된 계정 목록, 각각 이름 수정, 체크박스로 사용 여부,
  마지막 감지 시각, `이 계정의 방 N개`.
- 계정이 1개뿐이면 홈·매크로 어디에도 계정 얘기를 꺼내지 않는다.

### 동작
- `KakaoListener.sendTo(ctx, RoomRef, text)` — 그 계정의 세션으로만 보낸다.
- 발송·트리거·자동응답·봇 전부 **선택된 계정의 방만** 대상으로 한다.
- 세션 맵 키도 `RoomRef.key()` 로 바꾼다.

## 7. 봇 탭

지금은 세그먼트로 두 봇을 한 화면에 욱여넣었다. 매크로와 같은 방식으로 바꾼다.

```
  봇
┌─────────────────────────────────────┐
│  방 관리봇      켜짐 · 방 2개        › │
│  미니게임봇     꺼짐                › │
└─────────────────────────────────────┘
```
각각 전용 서브화면. 서브화면 안도 목록형(제목+값+›)으로 통일한다.

## 9. 새로 필요한 컴포넌트 (`Ui.java` / `Nav.java`)

전부 기존 `Theme` 토큰만 쓴다. 색·dp 리터럴 금지.

```java
// Nav — 서브화면 스택
static void push(MainActivity a, String title, View content)
static boolean pop()                      // 스택이 비었으면 false (뒤로가기 키가 쓴다)
static boolean inSub()                    // 서브화면에 있나 (탭바 숨김 판단)

// Ui — 목록형 행
static LinearLayout navRow(Context c, String title, String value, int valueColor, Runnable onTap)
static LinearLayout navRowSwitch(Context c, String title, String sub, boolean on, Ui.OnToggle cb)
static LinearLayout group(Context c)      // 카드 안에 행들을 넣고 사이에 구분선을 자동으로 넣는 컨테이너
static LinearLayout checkRow(Context c, String title, String sub, String[] badges,
                             boolean checked, Ui.OnToggle cb, Runnable onDelete)  // onDelete null 이면 ✕ 없음
static View snack(Context c, String msg, String action, Runnable onAction)        // 5초 되돌리기
static TextView badge(Context c, String text, int color)                          // 작은 배지 (단체 / 1:1)
```

`navRow` 의 값 글자는 우측 정렬, `›` 는 DIM, 값이 길면 ellipsize END.
행 높이는 최소 `Theme.dp(56)`, 탭 영역 전체가 눌려야 한다(누르면 alpha 0.7).

## 10. 하지 말 것

- 카드 안에 카드를 넣지 마라.
- 같은 화면에 아코디언과 목록행을 섞지 마라 (내정보 "고급" 하나만 예외).
- 설명 문구를 두 줄 넘게 쓰지 마라. 길면 그 설정이 잘못 설계된 거다.
- 이모지를 장식으로 쓰지 마라. 상태 표시(⚠)에만 절제해서.
- 기능을 없애지 마라. **배치만 바꾼다.** 지금 있는 설정은 전부 어딘가에서 접근 가능해야 한다.
