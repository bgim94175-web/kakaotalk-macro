# UI v4b — 시각 체계

> 화면 구조(탭 · 서브화면 · 행 규칙)는 `docs/UI_V3.md` 를 그대로 따른다.
> 문구는 `docs/TONE.md` 를 따른다.

밝은 업무용 화면이다. 토스 · 카카오뱅크 · 삼성 One UI 처럼, 흰 목록과 가는 구분선, 시스템 산세리프로 읽힌다.
기능은 화면 전체를 다시 칠하지 않고, 작은 색 막대와 칩으로만 구분한다.

## 1. 바탕 · 글자 · 조작

| 토큰 | 값 | 용도 |
|---|---|---|
| `BG` | `#F2F4F6` | 화면 바탕 |
| `CARD` / `BG2` | `#FFFFFF` | 목록 · 탭바 |
| `TEXT` / `SUB` / `DIM` | `#191F28` / `#4E5968` / `#8B95A1` | 본문 · 보조 · 비활성 |
| `LINE` | `#E5E8EB` | 행 구분선 |
| `PRIMARY` | `#3182F6` | 주 버튼 · 스위치 · 체크. 화면이 달라도 같다 |
| `OK` / `AMBER` / `RED` | `#087F5B` / `#E67700` / `#E03131` | 정상 · 설정 필요 · 오류 |

- 글자는 시스템 산세리프(`sans-serif` / Roboto, 한글은 기기의 Noto Sans KR). 세리프를 쓰지 않는다.
- 제목 20sp, 목록 제목 16sp, 본문 14sp, 보조 13sp. 본문 줄간격은 1.5.
- 여백은 8dp 그리드. 화면 좌우 16dp, 목록 행 최소 56dp, 모서리 8dp, 칩 4dp.
- 스위치 트랙만 완전히 둥글다. 버튼·칩·카드를 알약으로 만들지 않는다.
- 영문 머리글, 큰 세리프 숫자, 그라데이션, 광택, 선 아이콘 세트를 쓰지 않는다.

## 2. 기능별 포인트

포인트 색은 제목 옆 3dp 막대, 상태 칩, 목록 왼쪽 막대에만 쓴다.

| 기능 | 색 |
|---|---|
| 홈 · 내정보 · 시작 설정 | `#3182F6` |
| 자동발송 | `#1B64DA` |
| 경쟁사 저격 | `#5F3DC4` |
| 갠톡 자동응답 | `#0B7285` |
| 대화방 관리봇 | `#087F5B` |
| 미니게임봇 | `#C2255C` |
| 보낼 방 | `#495057` |

관리자 탭: 키 `#3182F6`, 주문 `#087F5B`, 입금 `#0B7285`, 기록 `#5F3DC4`, 설정 `#495057`.
주문 카드의 기능 칩은 사용자앱과 같은 색을 쓴다.

`Theme.setAccent` 는 그 막대·칩용이다. 버튼·스위치·체크는 `Theme.PRIMARY` 다.

## 3. 구성

| 요소 | 설명 |
|---|---|
| `pageHead` | 탭 제목. 색 막대 + 한글 제목. 영문 머리글과 태그라인은 그리지 않는다 |
| `hero` | 흰 카드. 색 막대 + 한글 제목 + 설명 한 줄. 메달·그라데이션 없음 |
| `navRow` / `fnRow` | 목록 행. 제목, 현재 값, `›`. 기능 행은 왼쪽 색 막대 |
| `group` | 흰 목록. 행 사이 1dp 구분선 |
| 탭바 | 한글 라벨. 선택된 탭은 굵은 글자와 색 막대 |

## 4. 시작 설정 · 이미지

시작 설정(`Setup`)과 이미지 화면(1~5장, 전송 조건, 즉시 전송)의 동작은 그대로다.
접근성 서비스 선언은 바꾸지 않는다. 이미지 전송 엔진 호출(`MacroDetail.image` / `sendImagesNow`, `ImageSender.sendWithResult`)도 바꾸지 않는다.
