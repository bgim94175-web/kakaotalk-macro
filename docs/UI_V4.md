# UI v4 — 시각 체계 명세

> 화면 구조(탭 · 서브화면 · 행 규칙)는 `docs/UI_V3.md` 를 그대로 따른다. v4 는 **시각 체계**만 바꾼다.
> 문구는 `docs/TONE.md` 를 따른다.

목표: 고급스럽고 단정한 업무용 인상. 그리고 **기능마다 색·아이콘·머리 카드가 달라서 지금 어느 기능을
만지고 있는지 한눈에 구분**되는 것.

---

## 1. 바탕 · 글자 · 브랜드

| 토큰 | 값 | 용도 |
|---|---|---|
| `BG` / `BG2` | `#0A0B0F` / `#0F1116` | 오닉스 바탕 · 탭바 |
| `CARD` / `CARD2` | `#15171D` / `#1C1F27` | 카드 · 입력칸 |
| `TEXT` / `SUB` / `DIM` | `#F2EEE6` / `#A39E95` / `#6B675F` | 아이보리 글자 계열 |
| `GOLD` | `#D4B27A` | 브랜드 (로고 · 홈 · 내정보 · 관리자 키) |
| `OK` / `AMBER` / `RED` | `#74D39A` / `#F79A5B` / `#EF6F6F` | 정상 · 설정 필요 · 오류/경보 |

- 제목 · 큰 숫자는 세리프 굵게(`Theme.serif()`). 본문은 기본 산세리프.
- 영문 머리글(eyebrow)은 10.5sp · 자간 0.22 · 기능 색. 예: `AUTO SEND`, `SECURITY AUDIT`.
- 이모지는 쓰지 않는다. 모든 표식은 `Icon` 선 아이콘(24 격자 · 1.6 획)으로 그린다.

## 2. 기능별 액센트

### KakaoAuto

| 기능 | 색 | 아이콘 | 머리글 |
|---|---|---|---|
| 홈 · 시작 설정 | 골드 `#D4B27A` | HOME / SPARK | `KAKAO AUTO` / `GETTING STARTED` |
| 자동발송 매크로 | 사파이어 `#84A3F6` | SEND | `AUTO SEND` |
| 메시지 추적 | 자수정 `#B39AF3` | BOLT | `TRIGGERS` |
| 개인 대화 자동응답 | 아쿠아마린 `#5FC6DC` | REPLY | `AUTO REPLY` |

| 미니게임봇 | 로즈 `#EE8FB2` | DICE | `MINI GAME` |

### KakaoAdmin

| 탭 | 색 | 아이콘 | 머리글 |
|---|---|---|---|
| 키 | 골드 | KEY | `LICENSE KEYS` |
| 주문 | 제이드 `#5ECC9C` | RECEIPT | `ORDERS · DEPOSITS` |
| 입금(주문 탭 안) | 아쿠아마린 `#5FC6DC` | — | 수동 매칭 버튼 |
| 기록 | 자수정 `#B39AF3` (경보는 RED + WARN) | SHIELD | `SECURITY AUDIT` |
| 설정 | 펄 `#C3CAD6` | GEAR | `SETTINGS` |

주문 카드의 기능 칩은 사용자앱과 같은 색(매크로 사파이어 · 관리봇 제이드 · 미니게임 로즈)을 쓴다.

### 액센트 적용 규칙

- `Theme.setAccent(color)` 로 지금 화면의 색을 정하고, 스위치 · 체크 · 세그먼트 · 주 버튼 · 구역 머리말 점이
  `Theme.accent()` 를 따른다. 뷰는 **만들 때** 색을 잡으므로 화면을 만들기 직전에 바꾼다.
- KakaoAuto: 탭 이동 시 `Nav.tabColor(tab)`, 서브화면 진입 시 해당 기능 색. 뒤로 가면 이전 색으로 돌아간다.
- KakaoAdmin: `MainActivity.goTab()` / `reloadCurrent()` 에서 탭 색으로 바꾼다. 로그인 화면은 골드.
- 상태색(OK/AMBER/RED)은 액센트와 별개다. 기능 색을 상태 표시에 쓰지 않는다.

## 3. 구성 요소 (`Ui`)

| 요소 | 설명 |
|---|---|
| `pageHead` | 탭 화면 머리 — 기능 색 짧은 선 + 머리글 + 세리프 제목 + 한 줄 설명 (Auto) |
| `hero` | 기능 머리 카드 — 기능 색이 왼쪽 위에서 번지는 면 + 원형 메달 + 머리글 + 세리프 이름 + 설명. 아래에 `stat` · 스위치를 잇는다 |
| `stat` / `statTile` | 세리프 큰 숫자 + 작은 라벨 (Admin 은 아이콘 포함 타일) |
| `iconTile` / `medallion` | 기능 색 14% 면 + 26~38% 테두리 안의 선 아이콘 |
| `navRow` / `fnRow` | 목록 행 — 왼쪽 기능 아이콘 타일, 오른쪽 현재 값 또는 상태 칩 |
| `stepRow` | 시작 설정 단계 — 번호/체크 원 + 필요·권장·완료 칩 + 동작 버튼 |
| `cardHead` | 카드 제목 줄 — 아이콘 타일 + 제목 (Admin 설정) |
| 탭바 | 선 아이콘 + 라벨. 선택된 탭은 해당 탭 색 16% 알약 배경 + 아이콘 색 |

## 4. 시작 설정 (KakaoAuto `Setup`)

라이선스 인증 직후 한 번 자동으로 열리고, 홈 맨 위 `시작 설정` 카드(미완료 시)와 내정보 → `권한 · 시작 설정` 에서 다시 연다.

| 단계 | 구분 | 완료 판정 |
|---|---|---|
| 알림 접근 허용 | 필요 | 알림 리스너 활성 |
| 배터리 최적화 제외 | 필요 | `isIgnoringBatteryOptimizations` |
| 정확한 알람 허용 (Android 12+) | 권장 | `canScheduleExactAlarms` |
| 알림 표시 허용 (Android 13+) | 권장 | `POST_NOTIFICATIONS` 권한 |
| 대화방 감지 | 권장 | 감지된 대화방 1개 이상 |
| 발송 메시지 작성 · 대상 대화방 선택 | 필요 (매크로 이용 시) | 매크로 설정 값 |

- 각 단계는 설명 한 줄과 버튼 하나만 둔다. 완료된 단계는 버튼 대신 `완료` 칩.
- 필수 단계가 남아 있으면 홈 카드가 남은 건수와 진행 막대를 보여준다. 필수 단계가 모두 끝나면 홈 카드는 사라진다.
- 제조사별 배터리 안내(삼성 · 샤오미 · 화웨이 · 오포 등)는 배터리 단계 설명에 덧붙인다.
- 접근성 서비스 · 다른 앱 위에 표시 권한은 이 흐름에 넣지 않는다 (백그라운드 전용 원칙).

## 5. 이미지 첨부 화면

이미지 전송 방식(백그라운드 LOCO)은 엔진 쪽에서 교체 중이므로 UI 는 방식과 무관하게 둔다.

- 매크로당 1~5장 선택 · 순서 유지 · 선택 해제만 제공한다.
- 전송 조건(모드 · N회마다)과 즉시 전송 버튼만 둔다. 접근성/첨부 흐름 진단 UI 는 두지 않는다.
- 실패 기록은 내정보 → `이미지 전송 기록` 에 일반 문구(시각 · 대화방 · 사유)로만 보여준다.
