# 내장 비속어 사전 — 검증한 입력 (Profanity.java)

`Profanity.hit()` 을 JVM 에서 직접 돌려 확인한 결과다. 어간 목록이나 되돌리기
순서를 고치면 **이 표를 다시 돌려 전부 통과하는지 확인한 뒤** 커밋해라.
`fold` 의 4단계 순서를 바꾸면 잡히던 것이 조용히 빠진다.

검증 방법 (안드로이드 SDK 없이 돈다 — 이 클래스는 안드로이드 API 를 쓰지 않는다):

```
mkdir -p /tmp/pt/out && cp android/auto/java/com/buseong/kakaoauto/Profanity.java /tmp/pt/
# T.java 는 아래 표를 그대로 ck("입력", 기대값) 으로 옮겨 적는다
javac -d /tmp/pt/out /tmp/pt/Profanity.java /tmp/pt/T.java && java -cp /tmp/pt/out T
```

## 걸리면 안 되는 것 (오탐 회귀 검사)

평범한 장사 대화다. 하나라도 걸리면 그 상태로 내보내면 안 된다 —
방장이 광고하려고 켠 봇이 손님에게 경고를 쏘게 된다.

| 입력 | 되돌린 글 | 왜 안 걸려야 하나 |
|---|---|---|
| `시발점` | (빈 글) | 기본 예외 (始發點) |
| `오늘 시발점에서 만나요` | 오늘에서만나요 | 기본 예외 |
| `시발역 근처입니다` | 근처입니다 | 기본 예외 |
| `안녕하세요 반갑습니다` | — | 평문 |
| `가격 문의드립니다` | — | 평문 |
| `로벅스 구매 가능한가요` | — | 평문 |
| `12시에 발송됩니다` | 12시에발송됩니다 | 숫자 제거가 「시발」 을 만들지 않는지 확인 |
| `이거 시간 좀` | 이거시간좀 | 「이」 제거가 어간을 만들지 않는지 확인 |
| `비싸네요` | — | 평문 |
| `개발자입니다` | 개발자입니다 | 「개」+「발」 이 붙어도 어간이 아님 |
| `사이비 종교` | 사비종교 | 「이」 제거의 부작용 확인 |
| `미친 듯이 좋아요` | 미친듯좋아요 | 「미친」 단독은 어간이 아님 (`미친놈`·`미친년`·`미친새끼` 만) |

## 알려진 오탐 — 고치지 않고 예외로 메운다

| 입력 | 결과 | 설명 |
|---|---|---|
| `개 새끼 고양이` | `개새끼` 로 걸린다 | 공백을 지우면 어간이 만들어진다. 되돌리기를 약하게 하면 「개 새 끼」 우회가 통과하므로, 판정을 고치는 대신 **예외 단어**로 메운다 |

되돌리기를 세게 할수록 오탐이 늘고 약하게 할수록 우회가 는다. 둘 중 하나를 고르는
문제가 아니라 예외 목록으로 메우는 문제다. 그래서 기능 기본값이 **꺼짐**이고,
화면에 「시험해 보기」 를 둔다 — 방에서 오탐이 터진 뒤에 알면 이미 늦다.
