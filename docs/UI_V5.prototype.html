동작 방식

휴대폰은 계정을
등록할 때만 필요합니다

카카오 계정을 등록하면 K bot 서버가 접속을 유지하고, 계정마다 켠 기능을 실행합니다. 콘솔은 PC와 휴대폰 브라우저에서 엽니다.

  1. 구매 신청

    기능과 기간을 고르고 표시된 금액을 입금합니다. 금액이 일치하면 통상 1~2분 내 키가 발급됩니다.

    구매 페이지
  2. 계정 등록

    콘솔에 카카오 계정을 입력하고, 휴대폰 카카오톡에 표시된 입력란에 번호를 입력합니다.

    콘솔 · 휴대폰
  3. 기능 켜기

    계정마다 매크로, 입장·퇴장 로그, 금지어 검열 등을 켜고 적용할 방을 고릅니다.

    콘솔
