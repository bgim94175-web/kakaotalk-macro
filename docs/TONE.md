# 문구 규칙 (Tone & Voice)

앱·웹·문서의 **모든 사용자 노출 문구**에 적용한다. 예외 없음.

## 기준

**비즈니스 문어체.** 간결하고 중립적으로. 사용자를 응대하는 서비스가 아니라, 상태를 보고하는 도구처럼 쓴다.

## 하지 말 것

| 금지 | 이유 |
|---|---|
| 반말 (`~해`, `~야`, `~거든`, `~줘`) | 이전 버전의 문제. 전부 제거 |
| 과도한 친절 (`~해볼게요`, `걱정 마세요`, `같이 확인해봐요`) | 도구가 사용자를 달랠 필요 없음 |
| 감탄사·이모지 장식 (`!`, `😊`, `✨`) | 상태 표시(`⚠`)만 허용 |
| 1인칭 주체 (`내가`, `제가 ~할게요`) | 앱은 행위자가 아니라 시스템 |
| 사과 (`죄송합니다`, `미안`) | 오류는 사과 대신 원인과 조치를 제시 |
| 불필요한 부연 | 한 문장으로 끝낼 것을 세 문장으로 늘리지 않는다 |

## 할 것

- **합니다체** 또는 **명사형 종결**을 상황에 맞게 사용
  - 본문·안내: 합니다체 (`발송 가능합니다`)
  - 라벨·요약·상태: 명사형 (`설정 필요`, `발송 대기`, `권한 없음`)
- **버튼은 동사 명령형 또는 명사형**, 2~5자 권장 (`저장`, `즉시 발송`, `권한 설정`)
- **오류 문구는 [현상] + [조치]** 구조. 원인 추측은 확실할 때만
- 숫자·단위는 명확하게 (`20~40분`, `최대 5장`, `1일 200회`)

## 변환 예시

| 이전 | 이후 |
|---|---|
| 카톡 알림 답장으로 보낸다. 그 방 알림이 한 번은 와야 발송할 수 있어. | 카카오톡 알림 답장으로 발송합니다. 대상 대화방의 알림이 1회 이상 수신되어야 발송이 가능합니다. |
| 접근성 권한이 꺼져 있어서 사진은 못 보내. 텍스트 발송은 영향 없어. | 접근성 권한이 비활성 상태입니다. 이미지 전송이 불가하며, 텍스트 발송은 정상 동작합니다. |
| 지금 한 번 보내기 | 즉시 발송 |
| 구매했는데 안 켜졌어 (새로고침) | 구매 내역 새로고침 |
| 사진은 5장까지야 | 이미지는 최대 5장까지 첨부됩니다 |
| 아직 감지된 방이 없어. 카톡에서 메시지를 한 번 받으면 여기 뜨고, 그 전엔 직접 입력해도 돼. | 감지된 대화방이 없습니다. 카카오톡 메시지를 1회 수신하면 자동으로 등록되며, 직접 입력하여 추가할 수도 있습니다. |
| 다른 기기에서 접속돼서 이 기기는 잠겼어 | 다른 기기에서 인증되어 현재 기기가 잠금 처리되었습니다 |
| 키 1개당 기기 1대만 쓸 수 있어 | 라이선스 키 1개당 기기 1대만 등록됩니다 |
| 방을 못 찾았어 — 카톡 버전이 바뀌었을 수 있어 | 대화방을 찾지 못했습니다. 카카오톡 화면 구성이 변경되었을 수 있습니다. |
| 화면 잠금을 '없음'으로 바꿔줘 | 화면 잠금 방식을 '없음'으로 설정하십시오 |
| 48시간 안에 입금하지 않으면 주문이 자동 취소돼 | 48시간 내 미입금 시 주문이 자동 취소됩니다 |

## 용어 — 쉬운 말 사용

화면에 보이는 문구에는 아래 왼쪽 용어를 쓰지 않는다. 오른쪽으로 바꿔 쓴다.
코드 주석·변수명은 왼쪽 용어를 그대로 써도 된다 (개발자용이므로).

| 쓰지 않는 용어 | 화면 표기 |
| --- | --- |
| 전역 / 글로벌 | 전체 기본값 |
| 오버라이드 / 덮어쓰기 | 개별 설정 |
| 쿨다운 | 쿨타임 |
| 세션 | 대화방 연결 / 접속 |
| 치환 / 치환 토큰 | 실제 값으로 바뀝니다 / `{방}` `{이름}` 같은 표시 |
| 인텐트 | 실행 정보 / 열기 정보 |
| 문자열 | 단어 / 글자 |
| 대기열 / 큐 | 대기 목록 |
| 리스너 | 알림 읽기 권한 |
| 지문 / 핑거프린트 | 기기 고유정보 |
| 폴백 | 예비 방식 |
| 스레드 / 프로세스 | 작업 |
| 컨텍스트 | 앱 정보 |
| 액티비티 | 화면 |
| 스택트레이스 | 오류 상세 |

| nonce / 토큰 | 확인값 / 코드 |

| 비교 방식 | 찾는 방식 |

| 정규식 | 정규식(고급) — 설명에 "잘 모르면 「포함」" 을 붙인다 |

### 뜻이 다른데 헷갈리는 말 — 반드시 갈라 쓴다

| 화면 표기 | 무엇인가 | 섞어 쓰면 |
| --- | --- | --- |
| 방 공지 | 방장·부방장이 **그 방에 올려 둔** 공지사항 (앱은 읽기만) | 손님이 "내가 쓴 글이 방에 올라갔나" 로 오해한다 |
| 공지문 | 사장이 적어 두고 봇 명령(`!공지`)으로 **뿌리는** 글 | 같은 사고 |

같은 뜻에 두 용어를 섞어 쓰지 않는다 (쿨타임/쿨다운, 1일/하루 등).
새 문구를 넣을 때 이 표에 없는 외래어·약어가 필요하면, 먼저 우리말 표현을 찾는다.

## 적용 범위

1. 안드로이드 사용자앱 (`android/auto/`) — 화면 문구, 버튼, 로그, 토스트, 다이얼로그
2. 안드로이드 관리자앱 (`android/admin/`) — 동일
3. 구매 웹사이트 (`public/`) — 랜딩, 구매, 주문, 키 조회
4. 서버 응답 중 사용자에게 보이는 문구 (`lib/`, `routes/`)
5. 운영 문서 (`DEPLOY.md`, `docs/*.md`, `android/README.md`)

## 코드 주석

주석은 **개발자용**이므로 친근한 설명체를 유지해도 된다. 단 반말은 통일해서 쓰고,
사용자 노출 문구와 혼동되지 않게 한다. 주석 때문에 문구 규칙이 흐려지면 안 된다.
