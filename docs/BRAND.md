# 서비스 이름 — K bot

서비스(웹사이트·관리 콘솔)의 이름은 **K bot** 이다. 2026-10 결정.

## 표기 규칙

- 영문 그대로 `K bot` — 대문자 `K`, 한 칸 띄고 소문자 `bot`.
- 쓰지 않는 표기: `KBot`, `K-bot`, `Kbot`, `케이봇`, `K Bot`.
- 한국어 문장 안에서도 `K bot` 그대로 쓴다. 조사는 발음대로 붙인다: `K bot은`, `K bot에서`.
- 기존 명칭 `카카오톡 매크로` / `카톡 매크로` 는 **상품(기능) 설명**에만 남긴다. 사이트·콘솔의 이름으로는 쓰지 않는다.

## 쓰이는 곳

| 위치 | 표기 |
| --- | --- |
| 모든 페이지 `<title>` | `<화면 이름> · K bot` (홈은 `K bot`) |
| 상단 바 브랜드 | `K bot` (파비콘 + 글자) |
| 관리 콘솔(`/panel`) 제목 | `K bot` 콘솔 — 화면 제목은 `관리 · K bot` |
| 브라우저 탭 안 읽음 표시 | `(N) K bot` |
| 파비콘 `aria-label` | `K bot` |

안드로이드 앱 패키지·앱 이름은 이 문서의 범위가 아니다(별도 결정 전까지 그대로 둔다).
