# K bot — 라이선스 서버 + 구매 웹 + 관리 콘솔 + 서버 발송

하나의 저장소에 **라이선스 서버 · 구매 웹사이트 · 웹 관리 콘솔 · 서버 측 카카오 발송**이 들어 있습니다.
제품은 **웹 콘솔(`/panel`) + 서버 발송(`sender/`)** 입니다. 안드로이드 앱은 단종되어 저장소에서 제거되었습니다.

| 구성 요소 | 위치 | 설명 |
|---|---|---|
| 라이선스 서버 | `server.js` `lib/` `routes/` | Render(Node) + Neon(Postgres). 키 검증 · 기능 권한 · 관리자 API · 자동 입금확인 |
| 구매 웹사이트 | `public/` | 동일 서버가 서빙. 단일 상품 안내 · 주문 · 키 조회 |
| 발송 콘솔 | `public/panel.html` `routes/panel.js` | 같은 서비스의 `/panel`. 라이선스 키로 들어가 카카오 계정을 등록하고 매크로·봇을 설정합니다. 오픈프로필 1:1 채팅(갠톡)을 이 화면에서 보고 답할 수도 있습니다(카카오톡을 열지 않습니다). 오픈 단체방은 이 목록에 올리지 않습니다. |
| 관리 콘솔 | `public/manage.html` `public/manage.js` | 같은 서비스의 `/manage`. 관리자 비밀번호(`ADMIN_PASSWORD`)로 키 발급·주문 승인·입금 수동 매칭을 수행하는 웹 화면입니다. `/admin/*` 비밀번호 API 를 호출합니다 |
| 서버 발송 | `sender/` | 라이선스 서버가 띄우는 자식 프로세스. 세션은 Neon `kakao_sessions`. 자식이 죽으면 부모가 다시 띄우고, 라이선스와 구매·콘솔 화면은 유지합니다 |

## 판매 구성 — 단일 상품

| 항목 | 값 |
|---|---|
| 상품명 | **K bot 1개월** |
| 가격 | **30,000원** (주문마다 뒷자리 1~99원이 붙어 예: `30,047원`) |
| 기간 | **30일** |
| 포함 기능 | **자동발송 매크로 · 대화방 관리봇 · 미니게임봇 — 3종 전부** |

- 기능별 개별 구매, 3개월·1년 플랜, 묶음 할인은 **없습니다.** 모든 구매는 3종 전부를 30일 제공합니다.
- 기존 키를 가지고 다시 구매하면(`target_key`) **그 키의 기능 3종이 각각 30일씩 연장**됩니다(`max(지금, 현재 만료)` 기준).
- 가격·기간은 `lib/pricing.js` 한 파일에서만 결정됩니다. 바꾸면 구매 웹·주문 금액·관리 콘솔에 모두 반영됩니다.

## 자동 구매 흐름

```
구매자가 /buy 에서 주문
      ↓  고유 금액 30,0XX 원 (기본 30,000 + 뒷자리 1~99)
은행이 판매자 폰에 입금 알림
      ↓  폰 자동화가 그 텍스트를 POST
POST /api/deposit-hook?t=DEPOSIT_TOKEN
      ↓  서버가 금액으로 주문을 특정
신규 키 발급 또는 target_key 연장
      ↓
/order/:id?t=token 에 키가 바로 표시
      ↓
구매자가 그 키로 /panel 로그인
```

## 빠른 시작

```bash
# 서버 문법 확인
npm run check

# 로컬 실행
npm start
```

접속 확인:

```
https://<배포주소>/          → 구매 랜딩 페이지
https://<배포주소>/buy       → 주문 폼
https://<배포주소>/panel     → 발송 콘솔 (라이선스 키로 로그인)
https://<배포주소>/manage    → 관리 콘솔 (ADMIN_PASSWORD 로 로그인)
https://<배포주소>/api/price → 가격 JSON
https://<배포주소>/health    → ok
```

## 필수 확인 제약

- **발송은 이 서버의 카카오 세션입니다.** 구매자는 `/panel` 에서 라이선스 키로 들어가 계정을 등록하고, 인증번호만 폰의 카카오톡에 입력합니다. 등록이 끝나면 그 계정은 서버 프로세스가 살아 있는 동안 발송합니다. 폰이 꺼져 있어도 발송은 계속됩니다.
- **항상 켜져 있다고 보장하지 않습니다.** 셀프핑은 약 10분마다 자기 주소를 불러 15분 무요청 잠듦을 늦출 뿐, 호출 실패·메모리 부족·무료 한도 정지를 막지는 못합니다.
- 외부에서 카카오톡 대화방의 **강제퇴장은 실행할 수 없습니다.** 대화방 관리봇은 경고 및 관리자 호출까지만 수행합니다.
- **자동 입금확인은 판매자 폰의 은행 알림 전달에 의존합니다.** 기기가 꺼져 있거나 인터넷이 끊기면 그 사이 입금은 자동 확인되지 않으며, `/manage` 에서 수동으로 매칭합니다.
