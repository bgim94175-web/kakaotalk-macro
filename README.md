# 카톡 매크로 / 봇 — 라이선스 서버 + 구매 웹 + 안드로이드 앱

한 저장소에 네 조각이 들어있다.

| 조각 | 위치 | 뭐냐 |
|---|---|---|
| 라이선스 서버 | `server.js` `lib/` `routes/` | Render(Node) + Neon(Postgres). 키 검증 · 기능별 권한 · 관리자 API · 자동 입금확인 |
| 구매 웹사이트 | `public/` | 같은 서버가 서빙. 3종 상품 · 주문 · 키 조회 |
| 사용자앱 KakaoAuto | `android/auto/` | `com.buseong.kakaoauto` · 매크로 · 방관리봇 · 미니게임봇 |
| 관리자앱 KakaoAdmin | `android/admin/` | `com.buseong.kakaoadmin` · 키/주문/기록/입금 관리 |

## 파는 것 — 기능 3종, 각각 따로 결제

| id | 이름 | 내용 |
|---|---|---|
| `macro` | 자동발송 매크로 | 방별 주기 발송 · 이미지 최대 5장 · 메시지 추적 · 오픈프로필 개인톡 자동응답 |
| `roombot` | 방 관리봇 | 금지어 · 도배 감지 · 입퇴장 인사 · 공지 |
| `minigame` | 미니게임봇 | 끝말잇기 · 숫자야구 · 주사위 · 가위바위보 · 퀴즈 · 랭킹 |

기능마다 만료일이 따로 돌아간다. 앱 홈에서 켜짐/꺼짐이 보이고, 꺼진 기능은 **[구매하기]** 버튼이 웹 구매 페이지로 보낸다.

## 빠른 시작

```bash
# 서버 문법 확인
npm run check

# APK 빌드 (ANDROID_HOME 필요 · build-tools + platform 34)
cd android && ./build.sh all     # → android/out/*.apk
```

## 꼭 알아둘 제약

- **매크로 앱은 안드로이드 전용.** 카톡 알림을 다른 앱이 읽고 답장하는 기능이 iOS에 없다. 우회 방법도 없다.
  (구매 웹사이트와 입금 확인용 단축어는 아이폰에서도 된다 — 파는 쪽 얘기다)
- **기존 v1.8 / v1.4 사용자는 앱을 삭제하고 새로 설치해야 한다.** 원본 서명 키가 없어서 덮어쓰기가 안 된다.
  v2.0부터는 `android/keystore/app.jks` 가 저장소에 있으니 다음 버전은 업데이트 설치가 된다 — **이 파일 잃지 마라.**
- **저장소는 Private으로 유지해라.** 서명 키가 들어있어서, 공개되면 리패키징 방어가 무력화된다 (`docs/ANTI_ABUSE.md`).
- 외부 앱은 카톡 방에서 사람을 **강제퇴장시킬 수 없다.** 방 관리봇은 경고 + 관리자 호출까지만 한다.
- 발송 대상 방은 **그 방의 카톡 알림이 최근에 한 번 와야** 잡힌다 (알림의 답장 버튼을 재사용하는 구조).
