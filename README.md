# K bot — 회원 서버 + 구매 웹 + 관리 콘솔 + 서버 발송

하나의 저장소에 **회원·결제 서버 · 구매 웹사이트 · 웹 콘솔 · 관리 콘솔 · 서버 측 카카오 발송**이 들어 있습니다.
제품은 **웹 콘솔(`/panel`) + 서버 발송(`sender/`)** 입니다. 안드로이드 앱은 단종되어 저장소에서 제거되었습니다.
설계 기준 문서는 `docs/ACCOUNTS_V1.md` 입니다.

| 구성 요소 | 위치 | 설명 |
|---|---|---|
| 회원·결제 서버 | `server.js` `lib/` `routes/` | Render(Node) + Neon(Postgres). 회원 계정(아이디·비밀번호, Google 연결) · 상품 권리 · 방 설치 · 관리자 API · 자동 입금확인 |
| 구매 웹사이트 | `public/` | 동일 서버가 서빙. 상품 3종 안내 · 회원가입·로그인 · 주문 · 내 계정 · 실시간 상담(채널톡) |
| 발송 콘솔 | `public/panel.html` `routes/panel.js` | 같은 서비스의 `/panel`. 회원 아이디로 로그인합니다. 카카오톡 매크로용 내 카카오 계정을 등록하고, 설치한 방(내 방)의 방 관리봇·미니게임봇을 방마다 설정합니다. 오픈프로필 1:1 채팅(갠톡)을 이 화면에서 보고 답할 수도 있습니다 |
| 관리 콘솔 | `public/manage.html` `public/manage.js` | 같은 서비스의 `/manage`. 관리자 비밀번호(`ADMIN_PASSWORD`)로 주문 승인·입금 수동 매칭·회원·K bot 계정·방 설치를 관리합니다. `/admin/*` 비밀번호 API 를 호출합니다 |
| 서버 발송 | `sender/` | 서버가 띄우는 자식 프로세스. 고객 카카오 계정(매크로)과 운영자 K bot 계정(방 관리봇·미니게임봇)의 접속을 유지합니다. 세션은 Neon `kakao_sessions`. 자식이 죽으면 부모가 다시 띄우고, 구매·콘솔 화면은 유지합니다 |

## 판매 구성 — 상품 3종

| 상품 | 가격 | 단위 | 동작 |
|---|---|---|---|
| **카카오톡 매크로** | **20,000원** | 1개월(30일), 1~12개월 | 고객 **자기 카카오 계정**으로 대화방 주기 발송 · 이미지 첨부 · 갠톡 응답 · 저격 규칙. 회원당 카카오 계정 3개 |
| **방 관리봇** | **15,000원** | 방 1개 · 기간 제한 없음 | 운영자 **K bot 계정**이 오픈채팅방에 들어가 입장·퇴장 로그 · 들낙 감지 · 나갔을 때 내보내기 · 프로필 로그 · 홍보 금지 · 가리기 · 금지어 검열 · 올킥 방지. 방장이 K bot 계정을 **부방장**으로 지정하면 자동으로 감지해 동작합니다 |
| **미니게임봇** | **15,000원** | 방 1개 · 기간 제한 없음 | K bot 계정이 방에 들어가면 바로 끝말잇기 · 숫자야구 · 주사위 · 가위바위보 · 퀴즈 · 랭킹을 진행합니다 |

- 모든 구매는 **회원 계정**에 붙습니다. 새 라이선스 키는 발급하지 않습니다. 기존 키는 회원가입 후 `/account` 에서 등록하면 남은 기간이 회원 계정으로 옮겨집니다.
- 주문 금액 = 매크로 개월 × 20,000 + 방 상품 줄 수 × 15,000 (할인 없음, 주문 1건 최대 540,000원). 주문마다 뒷자리 1~99원이 붙습니다(예: `35,047원`).
- 카카오톡 매크로를 다시 구매하면 **지금 만료일 뒤로** 30일씩 이어집니다. 만료된 경우 입금이 확인된 시점부터 다시 계산합니다.
- 방 상품은 설치할 방의 **오픈채팅 링크**를 붙여 넣어 삽니다. 한 방에 두 상품을 함께 둘 수 있고, 같은 K bot 계정이 둘 다 맡습니다. 권리는 그 방에 영구히 묶입니다.
- 가격은 `lib/pricing.js` 한 파일에서만 결정됩니다. 바꾸면 구매 웹·주문 금액·관리 콘솔에 모두 반영됩니다.

## 자동 구매 흐름

```
회원이 /buy 에서 상품을 고르고 주문 (방 상품은 오픈채팅 링크를 붙여 넣으면 K bot 계정이 방을 미리 조회)
      ↓  고유 금액 (총액 + 뒷자리 1~99원)
은행이 판매자 폰에 입금 알림
      ↓  폰 자동화가 그 텍스트를 POST
POST /api/deposit-hook?t=DEPOSIT_TOKEN
      ↓  서버가 금액으로 주문을 특정 → 회원 계정에 적용
카카오톡 매크로 기간 연장 · 방 설치 확정 + K bot 계정 배정
      ↓
K bot 계정이 방에 자동 입장 → 미니게임봇은 바로 동작, 방 관리봇은 부방장 지정을 기다렸다가 자동으로 사용 중
      ↓
/order/:id 와 콘솔 내 방에서 진행 상태 확인
```

## 빠른 시작

```bash

npm run check

# 로컬 실행
npm start
```

접속 확인:

```
https://<배포주소>/          → 구매 랜딩 페이지
https://<배포주소>/signup    → 회원가입
https://<배포주소>/buy       → 주문 폼 (로그인 필요)
https://<배포주소>/account   → 내 계정 (구매 내역 · 기존 키 등록)
https://<배포주소>/panel     → 발송 콘솔 (회원 아이디로 로그인)
https://<배포주소>/manage    → 관리 콘솔 (ADMIN_PASSWORD 로 로그인)

https://<배포주소>/health    → ok
```

## 필수 확인 제약

- **카카오톡 매크로는 이 서버의 카카오 세션으로 발송합니다.** 회원은 `/panel` 에서 내 카카오 계정을 등록하고, 인증번호만 폰의 카카오톡에 입력합니다. 등록이 끝나면 그 계정은 서버 프로세스가 살아 있는 동안 발송합니다. 매크로 기간이 끝나면 그 회원의 카카오 계정 접속을 멈추고, 다시 구매하면 이어서 접속합니다.
- **방 관리봇·미니게임봇은 운영자 K bot 계정이 방에 들어가 동작합니다.** 운영자는 `/manage` 에서 K bot 계정(봇마다 다른 닉네임)을 등록해 둡니다. 내보내기·가리기 같은 방 관리 기능은 K bot 계정이 그 방의 부방장일 때만 동작하며, 방장·부방장·제외할 사람은 내보내지 않습니다.
- **항상 켜져 있다고 보장하지 않습니다.** 셀프핑은 약 10분마다 자기 주소를 불러 15분 무요청 잠듦을 늦출 뿐, 호출 실패·메모리 부족·무료 한도 정지를 막지는 못합니다.
- **자동 입금확인은 판매자 폰의 은행 알림 전달에 의존합니다.** 기기가 꺼져 있거나 인터넷이 끊기면 그 사이 입금은 자동 확인되지 않으며, `/manage` 에서 수동으로 매칭합니다.
