# 카톡 매크로 / 봇 — 라이선스 서버 + 구매 웹 + 안드로이드 앱

하나의 저장소에 다섯 개의 구성 요소가 포함되어 있습니다.

| 구성 요소 | 위치 | 설명 |
|---|---|---|
| 라이선스 서버 | `server.js` `lib/` `routes/` | Render 무료 웹 서비스 하나(Node) + Neon(Postgres). 키 검증 · 기능별 권한 · 관리자 API · 자동 입금확인. 셀프핑은 이 부모에 있다. |
| 구매 웹사이트 | `public/` | 같은 서비스가 서빙. 3종 상품 · 주문 · 키 조회. |
| 발송 관리 | `public/panel.html` `routes/panel.js` | 같은 서비스. 라이선스 키로 들어가 카카오 계정을 등록하고 매크로를 고친다. 앱의 기기 등록은 바꾸지 않는다. |
| 카카오 발송 | `sender/` | 라이선스 서버가 띄우는 자식 프로세스. 세션은 Neon `kakao_sessions`. 자식이 죽으면 부모가 다시 띄우고, 라이선스와 구매 사이트는 유지한다. |
| 사용자앱 KakaoAuto | `android/auto/` | `com.buseong.kakaoauto` · 계정 등록과 설정. 등록 후 발송은 상시 프로세스가 한다. |
| 관리자앱 KakaoAdmin | `android/admin/` | `com.buseong.kakaoadmin` · 키/주문/기록/입금 관리 |

## 판매 구성 — 기능 3종, 기능별 개별 결제

| id | 이름 | 내용 |
|---|---|---|
| `macro` | 자동발송 매크로 | 방별 주기 발송 · 이미지 최대 5장 · 메시지 추적 · 오픈프로필 개인톡 자동응답 |
| `roombot` | 방 관리봇 | 금지어 · 도배 감지 · 입퇴장 인사 · 공지 |
| `minigame` | 미니게임봇 | 끝말잇기 · 숫자야구 · 주사위 · 가위바위보 · 퀴즈 · 랭킹 |

기능별 만료일은 개별적으로 적용됩니다. 앱 홈에서 활성/비활성 상태가 표시되며, 비활성 기능은 **[구매하기]** 버튼을 통해 웹 구매 페이지로 연결됩니다.

## 필수 확인 제약

- **발송 관리는 `/panel` 입니다.** 라이선스 키로 들어가고, 카카오 계정은 그 화면에서 등록합니다. 인증번호는 폰의 카카오톡에 한 번 입력합니다. 등록이 끝나면 발송은 서버 세션이 합니다. 안드로이드 앱은 그대로 두며, 키 하나당 기기 하나도 앱 쪽에 남아 있습니다.
- **기존 v1.8 / v1.4 사용자는 앱을 삭제한 뒤 재설치해야 합니다.** 원본 서명 키가 없어 덮어쓰기 설치가 불가합니다.
  v2.0 부터는 `android/keystore/app.jks` 가 저장소에 포함되어 있어 다음 버전은 업데이트 설치가 가능합니다 — **해당 파일을 분실하지 마십시오.**
- **저장소는 Private 으로 유지하십시오.** 서명 키가 포함되어 있어, 공개되는 경우 리패키징 방어가 무력화됩니다 (`docs/ANTI_ABUSE.md`).
- 외부 앱은 카카오톡 대화방에서 **강제퇴장을 실행할 수 없습니다.** 방 관리봇은 경고 및 관리자 호출까지만 수행합니다.
- 발송 대상 대화방은 서버에 등록한 카카오 계정의 대화방 목록에서 고릅니다. 오픈채팅방과 일반 채팅방만 나옵니다.
- **등록이 끝난 계정은 서버가 켜져 있는 동안 폰이 꺼져 있어도 보냅니다.** 셀프핑은 부모에 있고, 약 10분마다 자기 주소를 불러 15분 무요청 잠듦을 늦춥니다. 그 호출이 실패하거나, 프로세스가 메모리 부족으로 죽거나, 무료 한도로 인스턴스가 멈추면 그 사이에는 보내지 않습니다. 항상 켜져 있다고 보장하지 않습니다. 세션은 Neon 에 있고, 프로세스가 다시 뜨면 이어서 접속합니다. 배포는 `DEPLOY.md` 를 보십시오.
