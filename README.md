# K bot — 회원 서버 + 구매 웹 + 패널 + 판매 관리 + 서버 발송

하나의 저장소에 **회원·결제 서버 · 구매 웹사이트 · K bot 패널 · 판매 관리 · 서버 측 카카오 발송**이 들어 있습니다.
제품은 **K bot 패널(`/panel`) + 서버 발송(`sender/`)** 입니다. 안드로이드 앱은 단종되어 저장소에서 제거했습니다.
설계 기준 문서는 `docs/ACCOUNTS_V1.md` 입니다.

| 구성 요소 | 위치 | 설명 |
|---|---|---|
| 회원·결제 서버 | `server.js` `lib/` `routes/` | Render(Node) + Neon(Postgres). 회원 계정(아이디·비밀번호, Google 연결) · 구매한 이용 권리 · 봇을 설치한 방 · 관리자 API · 자동 입금 확인 |
| 구매 웹사이트 | `public/` | 같은 서버가 제공합니다. 상품 3종 안내 · 회원가입·로그인 · 구매 · 주문 조회 · 내 계정 · 문의하기(채널톡) |
| K bot 패널 | `public/panel.html` `routes/panel.js` | 같은 서비스의 `/panel`. 회원 아이디로 로그인합니다. 카카오톡 매크로로 발송할 내 카카오 계정을 등록하고, 봇을 설치한 방(내 방)마다 방 관리봇·미니게임봇을 설정합니다. 등록한 계정으로 온 갠톡(1:1 대화)도 받은 갠톡에서 보고 답할 수 있습니다 |
| 판매 관리 | `public/manage.html` `public/manage.js` | 같은 서비스의 `/manage`. 관리자 비밀번호(`ADMIN_PASSWORD`)로 로그인해 주문 승인 · 입금 수동 확인 · 회원 · K bot 계정 · 봇을 설치한 방을 관리합니다. `/admin/*` 비밀번호 API 를 호출합니다 |
| 서버 발송 | `sender/` | 서버가 띄우는 자식 프로세스. 고객 카카오 계정(매크로)과 운영자 K bot 계정(방 관리봇·미니게임봇)의 접속을 유지합니다. 세션은 Neon `kakao_sessions` 에 있습니다. 자식이 죽으면 부모가 다시 띄우고, 구매 웹과 패널 화면은 그대로 열립니다 |

## 판매 구성 — 상품 3종

| 상품 | 가격 | 단위 | 동작 |
|---|---|---|---|
| **카카오톡 매크로** | **15,000원** | 1개월(30일), 한 번에 1~12개월 | 고객 **자기 카카오 계정**으로 정해진 간격마다 자동 발송 · 이미지 첨부 · 갠톡 자동 응답 · 저격 규칙. 회원당 카카오 계정 3개 |
| **방 관리봇** | **10,000원** | 방 1개 · 기간 제한 없음 | 운영자 **K bot 계정**이 오픈채팅방에 들어가 입장·퇴장 기록 · 들낙 감지 · 나간 사람 재입장 차단 · 프로필 기록 · 홍보 금지 · 글 가리기 · 금지어 검열 · 올킥 감지 · 보이스룸 켜기(「!보룸켜기」, 48시간 유지)를 맡습니다. 방장이 K bot 계정을 **부방장**으로 지정하면 자동으로 확인하고 동작합니다 |
| **미니게임봇** | **10,000원** | 방 1개 · 기간 제한 없음 | K bot 계정이 방에 들어가면 바로 끝말잇기 · 숫자야구 · 주사위 · 가위바위보 · 퀴즈 · 추억의 검 강화 · 랭킹을 쓸 수 있습니다 |

가격 안내의 제목은 **매크로는 월 결제, 방 관리 · 미니게임 봇은 방마다 결제** 입니다.

- 모든 구매는 **회원 계정**(화면 이름 `내 계정`)에 붙습니다. 새 라이선스 키는 발급하지 않습니다. 예전에 받은 키는 회원가입 후 `/account` 에서 등록하면 남은 기간이 회원 계정으로 옮겨집니다.
- 주문 금액 = 매크로 개월 × 15,000 + 방마다 고른 봇(방 관리봇·미니게임봇) 수의 합 × 10,000 입니다. 할인은 없고, 주문 1건은 최대 440,000원입니다. 입금자를 구분하려고 주문마다 1~99원이 더해집니다(예: `30,047원`).
- 카카오톡 매크로를 다시 구매하면 **현재 만료일에 이어서** 30일씩 늘어납니다. 이미 만료된 경우에는 입금이 확인된 시점부터 다시 계산합니다.
- 방 관리봇·미니게임봇은 설치할 방의 **오픈채팅 링크**를 붙여 넣어 구매합니다. 한 방에서 두 봇을 함께 쓸 수 있고, 같은 K bot 계정이 둘 다 맡습니다. 이용 기간 제한이 없고, 봇을 **다른 방으로 옮기거나 같은 방에 다시 설치**하는 것은 패널의 방 상태 화면에서 직접 무료로 할 수 있습니다(옮기기는 방마다 24시간에 한 번, 다시 설치는 30분에 한 번).
- 가격은 `lib/pricing.js` 한 파일에서만 정합니다. 바꾸면 구매 웹 · 주문 금액 · 판매 관리에 모두 반영됩니다.

## 자동 구매 흐름

```
회원이 /buy 에서 상품을 고르고 [주문하기] (방 관리봇·미니게임봇은 오픈채팅 링크를 붙여 넣으면 K bot 계정이 방을 미리 조회)
      ↓  고유 금액 (총액 + 입금 구분용 1~99원)
은행이 판매자 폰에 입금 알림
      ↓  폰 자동화가 그 텍스트를 POST
POST /api/deposit-hook?t=DEPOSIT_TOKEN
      ↓  서버가 금액으로 주문을 찾아 회원 계정에 반영
카카오톡 매크로 기간 연장 · 봇을 설치할 방 확정 + K bot 계정 배정
      ↓
K bot 계정이 방에 자동 입장 → 미니게임봇은 바로 동작, 방 관리봇은 부방장 지정을 기다렸다가 자동으로 사용 중
      ↓
주문 조회(/order/:id)와 패널의 내 방에서 진행 상황 확인
```

```

```

## 꼭 알아 둘 제약

- **카카오톡 매크로는 이 서버의 카카오 세션으로 발송합니다.** 회원은 `/panel` 에서 내 카카오 계정을 입력하고, 화면에 나온 확인 번호를 휴대폰 카카오톡에 넣으면 등록이 끝납니다. 등록한 계정은 서버 프로세스가 살아 있는 동안 발송합니다. 매크로 기간이 끝나면 그 회원의 카카오 계정 접속을 멈추고, 다시 구매하면 이어서 접속합니다.
- **방 관리봇·미니게임봇은 운영자 K bot 계정이 방에 들어가 동작합니다.** 운영자는 `/manage` 에서 K bot 계정을 등록해 둡니다(방장이 구분할 수 있도록 봇마다 닉네임을 다르게). 내보내기·글 가리기 같은 방 관리 기능은 K bot 계정이 그 방의 부방장일 때만 동작하며, 방장·부방장·제외 대상은 내보내지 않습니다.
- **보이스룸은 봇이 켜 두기만 합니다.** 방장·부방장이 「!보룸켜기」를 치면 K bot 이 그 방의 보이스룸을 켜고 48시간까지 살려 둡니다(한 계정이 여러 방을 동시에 들 수 있습니다). 봇이 음성으로 말하거나 듣지는 않습니다. 켜기 신호를 카카오가 거절하면 방에 그대로 알립니다.
- **항상 켜져 있다고 보장하지 않습니다.** 셀프핑은 약 10분마다 자기 주소를 불러 15분 무요청 잠듦을 늦출 뿐, 호출 실패·메모리 부족·무료 한도 정지를 막지는 못합니다.
- **자동 입금 확인은 판매자 폰의 은행 알림 전달에 의존합니다.** 기기가 꺼져 있거나 인터넷이 끊기면 그 사이 입금은 자동으로 확인되지 않습니다. 이때는 `/manage` 에서 입금을 주문에 직접 연결해 주세요.
