동작 방식

휴대폰은 계정을
등록할 때만 필요합니다

카카오 계정을 등록하면 K bot 서버가 접속을 유지하고, 계정마다 켠 기능을 실행합니다. 콘솔은 PC와 휴대폰 브라우저에서 엽니다.

  1. 구매 신청

    기능과 기간을 고르고 표시된 금액을 입금합니다. 금액이 일치하면 통상 1~2분 내 키가 발급됩니다.

    구매 페이지
  2. 계정 등록

    콘솔에 카카오 계정을 입력하고, 휴대폰 카카오톡에 표시된 입력란에 번호를 입력합니다.

    콘솔 · 휴대폰
  3. 기능 켜기

    계정마다 매크로, 입장·퇴장 로그, 금지어 검열 등을 켜고 적용할 방을 고릅니다.

    콘솔

접근성 권한 · 이미지 발송용

질문

그 밖의 문의는 구매 신청 시 남긴 연락처로 안내합니다.

휴대폰 앱은 사용할 수 없습니다. 안드로이드 전용입니다. 이 앱은 카카오톡 알림을 읽고 해당 알림에 답장하는 방식으로 동작하며, iOS는 다른 앱의 알림을 읽거나 대신 답장하는 동작을 전면 차단하므로 우회 방법이 없습니다. 아이폰만 사용하는 경우 구매하지 마십시오. 이 사유로는 환불이 불가합니다.

웹 콘솔은 PC와 휴대폰 브라우저에서 열 수 있습니다.

대부분 즉시 사용 가능합니다. 주문 시 안내된 정확한 금액(뒷자리까지)을 입금하면 해당 금액으로 주문이 조회되어 통상 1~2분 내 자동으로 키가 발급됩니다. 주문 상태 페이지를 열어 두면 발급 시점에 키가 자동으로 표시됩니다. 입금 금액이 다르거나 동일 금액의 대기 주문이 중복되는 경우 관리자가 수동으로 처리하며, 수 시간이 소요될 수 있습니다.

콘솔에는 최대 8개까지 등록합니다. 설정과 기록은 계정마다 따로 저장되고, 받은함은 모든 계정의 1:1 대화를 한 목록으로 보여 줍니다. 답장은 그 대화를 받은 계정으로 발송됩니다.

등록이 끝난 계정의 발송과 기록은 서버가 수행하므로 휴대폰을 꺼도 동작합니다. 휴대폰은 계정을 등록할 때 카카오톡에 번호를 입력하는 데만 필요합니다. 서버가 멈춘 동안에는 보내지 않으며, 항상 켜져 있다고 보장하지 않습니다. 서버가 다시 시작되면 저장된 계정으로 이어서 접속합니다.

선택한 방에 누군가 들어오거나 나가면 [입장안내] 또는 [퇴장안내]를 보냅니다. 그 사람을 한 번 멘션하고, 오픈프로필 링크와 시각을 적습니다. 프로필 로그를 켜면 닉네임을 바꾼 사람에 대해 [프로필 변경 감지] 안내를 보냅니다. 기록은 두 기능을 켠 방에서만 남습니다.

막지 않습니다. 정해진 시간 안에 정해진 수 이상 강퇴가 일어나면 올킥으로 감지하여 기록합니다. 감지 시간(5~300초)과 강퇴 수(3~30건)는 계정마다 설정합니다. 강퇴된 사람을 다시 초대하지 않습니다.

이 계정이 해당 방의 부방장 이상일 때 동작합니다. 기본 욕설 목록과 직접 추가한 단어(최대 200개, 단어당 30자), 선택 시 링크가 들어간 글을 가립니다. 방장과 부방장이 올린 링크는 가리지 않으며, 사람을 내보내지 않습니다.

저장하지 않습니다. 계정을 등록할 때 로그인 확인에만 사용합니다. 로그인이 끊기면 콘솔에서 다시 등록해야 합니다.

사용할 수 없습니다. 키 1개는 기기 1대에만 등록됩니다. 최초 활성화한 기기에 고정되며, 다른 기기에서 동일 키를 입력하면 거부됩니다. 동일 키로 동시 접속을 시도하면 기존 기기가 잠금 처리됩니다.

휴대폰 교체 또는 초기화 시 관리자에게 기기 초기화를 요청하십시오. 초기화 완료 후 새 기기에서 재활성화할 수 있습니다.

가능합니다. 3종 모두 개별 결제이며, 만료일도 기능별로 별도 적용됩니다. 매크로만 구매하여 사용하거나, 이후 봇 기능만 추가할 수 있습니다. 3종 동시 구매 시 묶음 할인이 적용됩니다.

구매 신청 시 기존 키 항목에 사용 중인 키를 입력하십시오. 신규 키 발급 대신 해당 키의 남은 기간에 합산되며, 기기 고정도 그대로 유지됩니다.

1회 최대 5장입니다. 휴대폰 앱은 카카오톡 알림 답장으로 이미지를 전송할 수 없으므로, 공유 화면을 실행한 후 접근성 서비스가 화면을 조작하는 방식으로 전송합니다. 따라서 앱의 이미지 발송에는 접근성 권한이 필요합니다. 텍스트 발송은 접근성 권한 없이 동작합니다.

오픈프로필로 1:1 메시지가 수신되면 사전 등록된 문구를 자동 발송합니다. 문구는 직접 작성하며 {이름} {시간} 등을 넣으면 실제 값으로 바뀝니다. 동일 상대에게 다시 응답하지 않는 쿨타임을 설정할 수 있습니다.

감지 문구와 응답 문구를 한 쌍으로 등록하면, 대화방에서 해당 문구가 수신되는 즉시 응답을 발송합니다. 주기 발송과 독립적으로 동작합니다. 특정 대화방에서만 감지하거나, 감지한 방이 아닌 다른 방으로 발송하도록 설정할 수 있습니다.

수행할 수 없습니다. 카카오톡은 외부 앱의 멤버 강제퇴장을 허용하지 않습니다. 금지어 및 도배가 감지되면 경고 메시지 발송 + 관리자 호출로 처리합니다. 강제퇴장은 관리자가 직접 처리해야 합니다.

휴대폰 앱은 카카오톡 알림에 답장하는 방식으로 발송합니다. 따라서 최근 알림이 수신된 대화방에만 발송이 가능하며, 알림을 삭제했거나 대화방을 나간 경우 해당 방으로는 발송되지 않습니다. 카카오톡 업데이트로 이 방식이 차단될 수 있습니다. 발송 실패 시 앱 내 로그에 사유가 기록됩니다.

키 발급 전에는 주문번호를 전달하여 취소를 요청할 수 있습니다. 발급 후에는 키가 기기에 고정되므로 취소가 제한됩니다. 관리자에게 상황을 전달하여 협의하십시오.

안드로이드 전용임을 상단에 명시하고 있으므로, 아이폰 사용자의 착오 구매는 환불 대상이 아닙니다. 구매 전 반드시 사용 기기를 확인하십시오.
