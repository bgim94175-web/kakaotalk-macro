시작하기

4단계면 끝

  1. 기능을 골라 구매 신청 — 주문번호와 입금 계좌가 바로 떠. 금액 그대로 입금해줘.
  2. 키 발급 — 금액이 정확하면 보통 1~2분 안에 자동으로 발급돼. 주문 상태 페이지가 알아서 갱신되니까 그냥 열어두면 돼.
  3. 앱에 키 입력 — 앱을 열고 키를 넣으면 활성화돼. 이때 기기 1대에 고정돼.
  4. 권한 허용하고 설정 — 알림 접근 권한을 켜면 발송이 시작돼. 이미지 발송은 접근성 권한도 필요해.

다운로드 · 설치

앱 설치 안내

  1. APK 받기 — 구매가 승인되면 관리자가 설치 파일 링크를 알려줘. 플레이스토어에는 올라가 있지 않아.
  2. 출처를 알 수 없는 앱 허용 — 설정 → 앱 → 특별한 접근 → 알 수 없는 앱 설치. 브라우저/파일앱에 허용해줘.
  3. 알림 접근 권한 — 설정 → 알림 → 알림 접근 허용에서 앱을 켜줘. 카톡 알림을 읽고 답장하는 데 쓰여.
  4. 접근성 권한(이미지 발송용) — 이미지 첨부를 쓸 거면 접근성 서비스도 켜줘. 텍스트 발송만 쓸 거면 안 켜도 돼.
  5. 배터리 최적화 예외 — 백그라운드에서 앱이 죽지 않게 예외로 잡아줘.
i 앱 업데이트가 나오면 예전 버전은 서버에서 막힐 수 있어. 그때는 새 APK로 다시 설치하면 돼. 키와 설정은 그대로 남아.

자주 묻는 것

FAQ

아이폰에서도 돼?

안 돼. 안드로이드 전용이야. 이 앱은 카톡 알림을 읽고 그 알림에 답장하는 방식으로 동작하는데, iOS 는 다른 앱의 알림을 읽거나 대신 답장하는 걸 아예 막아놔서 방법이 없어. 아이폰만 쓰고 있으면 사지 마 — 환불도 어려워.

결제하면 바로 쓸 수 있어?

거의 바로 돼. 주문할 때 알려준 정확한 금액(뒷자리까지)을 입금하면 그 금액으로 주문을 찾아서 보통 1~2분 안에 자동으로 키가 발급돼. 주문 상태 페이지를 열어두면 발급되는 순간 키가 화면에 떠(직접 새로고침 안 해도 돼). 금액이 다르거나 같은 금액의 대기 주문이 겹치면 자동 확인이 안 되고 관리자가 직접 확인해 — 그때는 몇 시간 걸릴 수 있어. 발급된 키를 앱에 넣으면 그 순간부터 기간이 시작돼.

키 하나로 휴대폰 두 대에서 쓸 수 있어?

안 돼. 키 1개는 기기 1대에만 등록돼. 처음 활성화한 기기에 고정되고, 다른 기기에서 같은 키를 넣으면 거부돼. 같은 키로 동시 접속을 시도하면 먼저 쓰던 기기가 잠겨.

휴대폰을 바꾸거나 초기화했으면 관리자에게 기기 초기화를 요청해줘. 초기화해주면 새 기기에서 다시 활성화할 수 있어.

기능은 따로 사도 돼?

응, 3종 전부 별도 결제야. 만료일도 기능마다 따로 돌아가. 매크로만 사서 써도 되고, 나중에 봇만 추가해도 돼. 3개를 한 번에 사면 묶음 할인이 붙어.

연장은 어떻게 해?

구매 신청할 때 기존 키 칸에 쓰고 있는 키를 넣어줘. 그러면 새 키를 주는 대신 그 키의 남은 기간에 더해져. 기기 고정도 그대로 유지돼.

이미지는 몇 장까지 보내?

한 번에 최대 5장. 카카오톡은 알림 답장으로 이미지를 보낼 수 없어서, 공유 화면을 띄운 뒤 접근성 서비스가 대신 눌러주는 방식으로 보내. 그래서 이미지 발송은 접근성 권한이 필요해. 텍스트 발송은 권한 없이도 돼.

오픈프로필 개인톡 자동응답은 뭐야?

오픈프로필로 1:1 톡이 오면 미리 적어둔 문구를 자동으로 보내줘. 문구는 직접 쓰면 되고 {이름} {시간} 같은 치환 토큰을 쓸 수 있어. 같은 사람에게 다시 답하지 않는 쿨다운, 하루 최대 응답 수, 운영시간도 정할 수 있어.

메시지 추적은 어떻게 동작해?

감지할 문구와 보낼 답장을 짝지어 등록해두면, 어느 방에서든 그 문구가 올라오는 순간 바로 보내. 주기 발송과 따로 돌아가. 특정 방에서만 감지하거나, 감지한 방이 아닌 다른 방으로 보내게도 할 수 있어 (그 방에 최근 알림이 와 있어야 해).

방 관리봇이 강제퇴장도 해줘?

못 해. 카카오톡은 외부 앱이 멤버를 강퇴하는 걸 허용하지 않아. 그래서 금지어·도배가 잡히면 경고 메시지 + 관리자 호출로 처리해. 강퇴는 사람이 직접 해야 해.

발송이 안 될 수도 있어?

앱은 카톡 알림에 답장하는 방식으로 보내. 그래서 최근에 알림이 온 방에만 보낼 수 있고, 알림을 지웠거나 방을 나가면 그 방으로는 못 보내. 카카오톡이 업데이트되면서 방식이 막힐 수도 있어. 문제가 생기면 앱 안의 로그에 이유가 남아.

취소나 환불은?

키가 발급되기 전이면 주문번호를 알려주고 취소를 요청하면 돼. 발급된 뒤에는 기기에 고정되기 때문에 그냥은 어려워 — 관리자에게 상황을 말하고 상의해줘.

안드로이드 전용이라고 위에 크게 적어뒀으니까, 아이폰인데 샀다는 사유는 환불이 안 돼. 구매 전에 기기를 꼭 확인해줘.
