상품

기능 3종 · 개별 결제

기능을 선택하면 하단에 결제 금액이 계산됩니다. 3종 동시 선택 시 묶음 할인이 적용됩니다.

! 이 앱은 안드로이드 전용입니다. 아이폰에서는 다른 앱이 카카오톡 알림을 읽고 답장하는 것이 불가능하여(iOS 제약) 기술적으로 동작하지 않습니다. 구매 전 반드시 사용 기기를 확인하십시오.

시작하기

4단계면 끝

  1. 기능 선택 후 구매 신청 — 주문번호와 입금 계좌가 즉시 표시됩니다. 표시된 금액을 정확히 입금하십시오.
  2. 키 발급 — 입금 금액이 일치하면 통상 1~2분 내 자동 발급됩니다. 주문 상태 페이지는 자동 갱신되므로 페이지를 열어 두십시오.
  3. 앱에 키 입력 — 앱에서 키를 입력하면 활성화됩니다. 활성화 시점에 기기 1대로 고정됩니다.
  4. 권한 허용 및 설정 — 알림 접근 권한을 허용하면 발송이 시작됩니다. 이미지 발송에는 접근성 권한이 추가로 필요합니다.

다운로드 · 설치

앱 설치 안내

  1. APK 다운로드 — 구매 승인 후 관리자가 설치 파일 링크를 전달합니다. 플레이스토어에는 등록되어 있지 않습니다.
  2. 출처를 알 수 없는 앱 허용 — 설정 → 앱 → 특별한 접근 → 알 수 없는 앱 설치 에서 브라우저 또는 파일 앱에 권한을 허용하십시오.
  3. 알림 접근 권한 — 설정 → 알림 → 알림 접근 허용 에서 앱을 활성화하십시오. 카카오톡 알림을 읽고 답장하는 데 사용됩니다.
  4. 접근성 권한(이미지 발송용) — 이미지 첨부 기능 사용 시 접근성 서비스를 활성화하십시오. 텍스트 발송만 사용하는 경우에는 불필요합니다.
  5. 배터리 최적화 예외 — 백그라운드 종료를 방지하기 위해 배터리 최적화 예외로 등록하십시오.

자주 묻는 질문

FAQ

아이폰에서 사용할 수 있습니까?

사용할 수 없습니다. 안드로이드 전용입니다. 이 앱은 카카오톡 알림을 읽고 해당 알림에 답장하는 방식으로 동작하며, iOS 는 다른 앱의 알림을 읽거나 대신 답장하는 동작을 전면 차단하므로 우회 방법이 없습니다. 아이폰만 사용하는 경우 구매하지 마십시오. 이 사유로는 환불이 불가합니다.

결제 후 즉시 사용할 수 있습니까?

대부분 즉시 사용 가능합니다. 주문 시 안내된 정확한 금액(뒷자리까지)을 입금하면 해당 금액으로 주문이 조회되어 통상 1~2분 내 자동으로 키가 발급됩니다. 주문 상태 페이지를 열어 두면 발급 시점에 키가 자동으로 표시됩니다. 수동 새로고침은 필요하지 않습니다. 입금 금액이 다르거나 동일 금액의 대기 주문이 중복되는 경우 자동 확인이 불가하여 관리자가 수동으로 처리합니다. 이 경우 수 시간이 소요될 수 있습니다. 발급된 키를 앱에 입력한 시점부터 사용 기간이 시작됩니다.

키 1개로 휴대폰 2대에서 사용할 수 있습니까?

사용할 수 없습니다. 키 1개는 기기 1대에만 등록됩니다. 최초 활성화한 기기에 고정되며, 다른 기기에서 동일 키를 입력하면 거부됩니다. 동일 키로 동시 접속을 시도하면 기존 기기가 잠금 처리됩니다.

휴대폰 교체 또는 초기화 시 관리자에게 기기 초기화를 요청하십시오. 초기화 완료 후 새 기기에서 재활성화할 수 있습니다.

기능을 개별로 구매할 수 있습니까?

가능합니다. 3종 모두 개별 결제이며, 만료일도 기능별로 별도 적용됩니다. 매크로만 구매하여 사용하거나, 이후 봇 기능만 추가할 수 있습니다. 3종 동시 구매 시 묶음 할인이 적용됩니다.

사용 기간은 어떻게 연장합니까?

구매 신청 시 기존 키 항목에 사용 중인 키를 입력하십시오. 신규 키 발급 대신 해당 키의 남은 기간에 합산되며, 기기 고정도 그대로 유지됩니다.

이미지는 최대 몇 장까지 발송됩니까?

1회 최대 5장입니다. 카카오톡은 알림 답장으로 이미지를 전송할 수 없으므로, 공유 화면을 실행한 후 접근성 서비스가 화면을 조작하는 방식으로 전송합니다. 따라서 이미지 발송에는 접근성 권한이 필요합니다. 텍스트 발송은 접근성 권한 없이 동작합니다.

오픈프로필 개인톡 자동응답은 어떤 기능입니까?

오픈프로필로 1:1 메시지가 수신되면 사전 등록된 문구를 자동 발송합니다. 문구는 직접 작성하며 {이름} {시간} 등을 넣으면 실제 값으로 바뀝니다. 동일 상대에게 다시 응답하지 않는 쿨타임, 하루 최대 응답 수, 운영시간을 설정할 수 있습니다.

메시지 추적은 어떻게 동작합니까?

감지 문구와 응답 문구를 한 쌍으로 등록하면, 모든 대화방에서 해당 문구가 수신되는 즉시 응답을 발송합니다. 주기 발송과 독립적으로 동작합니다. 특정 대화방에서만 감지하거나, 감지한 방이 아닌 다른 방으로 발송하도록 설정할 수 있습니다 (대상 대화방에 최근 알림이 수신되어 있어야 합니다).

대화방 관리봇이 강제퇴장을 수행합니까?

수행할 수 없습니다. 카카오톡은 외부 앱의 멤버 강제퇴장을 허용하지 않습니다. 금지어 및 도배가 감지되면 경고 메시지 발송 + 관리자 호출로 처리합니다. 강제퇴장은 관리자가 직접 처리해야 합니다.

발송이 실패할 수 있습니까?

이 앱은 카카오톡 알림에 답장하는 방식으로 발송합니다. 따라서 최근 알림이 수신된 대화방에만 발송이 가능하며, 알림을 삭제했거나 대화방을 나간 경우 해당 방으로는 발송되지 않습니다. 카카오톡 업데이트로 이 방식이 차단될 수 있습니다. 발송 실패 시 앱 내 로그에 사유가 기록됩니다.

취소 및 환불 규정은 어떻게 됩니까?

키 발급 전에는 주문번호를 전달하여 취소를 요청할 수 있습니다. 발급 후에는 키가 기기에 고정되므로 취소가 제한됩니다. 관리자에게 상황을 전달하여 협의하십시오.

안드로이드 전용임을 상단에 명시하고 있으므로, 아이폰 사용자의 착오 구매는 환불 대상이 아닙니다. 구매 전 반드시 사용 기기를 확인하십시오.
