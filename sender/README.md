# 카카오 발송 자식

카카오 계정 등록이 끝난 뒤 매크로, 이미지, 경쟁사 저격, 갠톡 자동응답, 방 관리봇, 미니게임은 이 프로세스가 `agent-messenger` 로 보냅니다. 고객은 `/panel` 에서 라이선스 키로 들어와 계정을 등록합니다. 인증번호만 폰의 카카오톡에 입력하고, 그 뒤에는 이 프로세스의 세션이 보냅니다. 폰이 꺼져 있어도 이 프로세스가 살아 있는 동안은 발송이 계속됩니다. 무료 인스턴스의 셀프핑은 15분 잠듦을 늦출 뿐, 프로세스 사망이나 무료 한도 정지를 막지는 못합니다.

라이선스 서버(`server.js`)가 이 프로세스를 자식으로 띄웁니다. 별도 유료 웹 서비스는 없습니다. 자식이 예외로 죽거나 종료되면 부모는 `/health`, 라이선스, 구매 사이트를 유지한 채 자식을 다시 띄웁니다. 셀프핑은 부모에 있습니다. Render 인스턴스 전체가 메모리 부족으로 죽는 것은 막지 못합니다.

세션과 기능 설정은 라이선스 서버와 같은 Neon(`DATABASE_URL`)의 `kakao_sessions` 에 있습니다. 액세스 토큰과 리프레시 토큰만 `SENDER_KEY` 로 AES-256-GCM 봉인합니다. 재시작해도 등록은 지워지지 않습니다. 비밀번호는 받지 않습니다. 세션이 끊기면 발송을 멈추고, 앱은 계정을 다시 등록하라고 보여 줍니다.

## 환경 변수

라이선스 서비스 하나에 넣습니다. 값은 저장소에 적지 않습니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `DATABASE_URL` | 예 | 라이선스 서버와 같은 Neon 연결 문자열 |
| `SENDER_TOKEN` | 예 | 앱이 라이선스 응답으로 받는 값과 같아야 합니다 |
| `SENDER_KEY` | 예 | 토큰 봉인 키. 64자 hex 또는 긴 비밀 |
| `SENDER_PUBLIC_URL` | 아니오 | 비우면 이 서비스의 공개 주소를 앱에 알려 줍니다 |

부모가 자식을 `127.0.0.1` 에 붙이고 `/v1` 요청을 그쪽으로 넘깁니다. 앱이 쓰는 경로는 그대로입니다.
